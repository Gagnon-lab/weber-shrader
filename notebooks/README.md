# `sperm-data-analysis/notebooks`

This directory contains several notebooks to conduct the main analysis for the paper.

## Sub-directories
* `images/`: Images generated are outputted to this directory.

Files:
* `model_analysis.ipynb`: creates several figure plots, including
4C, 4D, 4E, 5A, 5B, 5C and supplemental figures/tables XXX.
* `sample_simulations.ipynb`: Creates the sample simulations used in Figure 4B.
* `sperm_decay.ipynb`: Estimates the sperm decay parameter $\delta = 6.28$ using Cattelan
and Gasparini (2021).
* `survivorship.ipynb`: Performs the survivorship analysis for Figure 5D and
supplemental figures/tables XXX.
* `tour.ipynb`: Not used in the paper, this file just gives an overview of the
model interface.
* `triplicate_noise.ipynb`: Estimates the sperm pseudocount parameter $M=472$.

## References
* Cattelan, S., & Gasparini, C. (2021). Male sperm storage impairs sperm quality in the zebrafish. Scientific reports, 11(1), 16689.
