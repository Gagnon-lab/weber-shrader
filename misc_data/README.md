# `sperm-data-analysis/misc_data`

This directory contains several miscellaneous data sets that were used for the results and figures.

## Sub-directories and files
* `OUTPUT_MP_TQ_extracted/`: Data for `notebooks/singleton_proportion.ipynb`.

* `cattelan_data.csv`: Data from Cattelan & Gasparini (2021) used in `notebooks/sperm_decay.ipynb`.
* `LongitudinalSpermSampling_SuccessSummary.xlsx`: Fish sampling time data used in `notebooks/fish_lifespan_sampling_course.ipynb`.

## References
* Cattelan, S., & Gasparini, C. (2021). Male sperm storage impairs sperm quality in the zebrafish. Scientific reports, 11(1), 16689.
